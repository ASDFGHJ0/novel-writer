# 墨屿 · 小说写作台

墨屿是一款纯前端、本地优先的小说写作工具。目前的核心亮点是可编辑、可演化的人物关系网：它既能根据正文中的人物共现生成线索，也允许作者手动建立和维护真实关系。

无需安装依赖或构建。作品数据保存在浏览器 `localStorage` 中，可导出 JSON 备份。

## 当前功能

- 四套可持久保存的界面主题：明亮、深色、水墨、未来
- 水墨主题使用宣纸暖白、墨色与克制朱砂；未来主题使用深空蓝、青紫关系线与低亮度光效
- 关系网升级为同屏工作区：人物档案摘要、关系阶段、故事事件和正文证据联动展示

### 写作工作台

- 多作品、分卷和章节管理
- 整部小说删除与独立回收站恢复；删除最后一部时自动建立空白作品
- 章节拖拽排序、重命名和全文搜索
- 正文自动保存、字数统计和每日写作目标
- 全书简介、章节大纲、角色、设定和灵感面板
- 角色常驻栏升级为摘要卡：展示身份、阵营、状态、档案完成度和证据数量
- 浅色/深色主题、专注模式和字号调整
- TXT 成稿导出、JSON 项目备份与导入

### 人物关系网

- 根据已建立角色在同段正文中的共现生成自动关系线索
- 手动新增、编辑、删除、断开和恢复人物关系
- 单向/双向关系、关系类型、描述、强度和章节范围
- 人物别名、阵营、势力、状态、颜色和节点形状
- 力导向、树状和环形三种布局
- 画布缩放、平移、节点拖动与聚焦
- 阵营筛选和自定义阵营颜色
- 章节时间轴、视角书签和人物路径查询
- 当前关系图导出 PNG、关系数据导出 JSON

### 故事资料库

- 历史版本与回收站恢复
- 正文选区标记角色及姓名/别名证据检索
- 完整人物档案、分类证据归档与取消归档
- 从正文生成档案候选：区分事实与推测，支持查看原文、忽略或确认写入
- 可选 OpenAI 兼容大模型接口：网页填写地址、模型与密钥，使用内置提示词生成档案草稿
- 内置 OpenAI、DeepSeek、通义千问、智谱 GLM 和 Google Gemini 常用模型预设，也可自定义接口
- AI 草稿写入前逐字段预览，默认只选择空白字段，避免覆盖作者设定
- 关系阶段按起止章节驱动关系网时间轴，并可关联事件与正文证据
- 人物知识时间线：记录“谁在何时知道什么”，发现可能提前知情的段落
- 人物一致性规则检查
- 故事事件轴与伏笔状态管理

## 使用方法

最简单的方式是双击 `index.html`。也可以启动本地静态服务器：

```powershell
cd novel-writer
python -m http.server 8000 --bind 127.0.0.1
```

然后打开 `http://127.0.0.1:8000`。

## 数据与备份

- 本地存储键：`moyu.writer.v1`
- 作品正文默认只存在当前浏览器中
- 清理浏览器站点数据可能导致作品丢失
- 建议定期通过应用导出 JSON 备份，并保存在浏览器数据之外
- AI 密钥默认仅保存在浏览器会话；勾选长期保存后会以明文存在本机 localStorage 中
- AI 请求只发送命中该角色姓名或别名的正文段落，发送前请确认所用接口的隐私政策

## 技术栈

- 原生 HTML、CSS、JavaScript
- HTML5 Canvas 2D
- `localStorage`
- 无框架、无第三方运行时依赖
