# 墨屿 · 小说写作台

一个纯前端的本地小说写作工具。双击 `index.html` 即可使用,无需安装、无需联网、无需构建。
所有数据保存在浏览器 localStorage 中,可随时导出 JSON 备份。

## 文件结构

| 文件 | 说明 |
| --- | --- |
| `index.html` | 页面骨架(顶栏 / 章节树 / 编辑器 / 侧栏面板) |
| `styles.css` | 全部样式,浅色 / 深色双主题,CSS 变量驱动 |
| `app.js` | 主逻辑:作品管理、章节树、编辑器、面板、搜索、导入导出 |
| `graph.js` | 人物关系网(`window.MoyuGraph`),从正文自动抽取人物共现关系 |

## 功能

- 多作品管理,分卷 / 章节树,支持拖拽排序、双击重命名
- 编辑器:自动保存(防抖 600ms)、字数统计、每日码字目标环
- 侧栏面板:全书简介与本章大纲、角色卡片、设定卡片、灵感Prompt、写作统计(近 7 天柱状图、连续写作天数)
- 全文搜索(标题 + 正文,结果带上下文高亮)
- 专注模式(Esc 退出)、浅色 / 深色主题、字号调节
- 人物关系网:自动从正文抽取人名与共现关系,支持手动添加关系、阵营 / 状态 / 形状等属性
- 导出成稿 TXT;项目 JSON 备份 / 导入

## 使用

直接用浏览器打开 `index.html`,或者起一个本地服务器:

```powershell
cd novel-writer
python -m http.server 8000
# 打开 http://localhost:8000
```

## 数据说明

- 存储键:`localStorage["moyu.writer.v1"]`
- 备份格式:`{ app: "moyu", version: 1, project: {...} }`,通过顶栏导出菜单生成
- 建议定期导出 JSON 备份,浏览器清理数据会清空 localStorage
